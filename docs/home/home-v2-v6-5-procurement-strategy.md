# Home V2 v6.5 Photography Procurement Strategy

**Date:** 2026-07-06
**Scope:** Final public Hero and Parent Confidence photography for `/home-v2`

## Decision Standard

The final image should make a Swiss parent feel that STOA is calm, serious, refined, and close to real family learning. It should not feel like generic tutoring stock, an AI product page, or a school advertisement.

## Procurement Paths

### Path A: Paid Stock Purchase

Use when a paid image clearly satisfies the v6.4 photography contract and can be licensed for STOA's public website.

Required before use:

- Source page URL.
- License agreement URL.
- Asset ID.
- Creator/vendor if available.
- Confirmation that the license covers public website/marketing use.
- Confirmation that no watermark or preview file is used.
- Confirmation that no visible school logo, private information, or third-party trademark appears.
- Record of identifiable people and endorsement risk.

### Path B: Commissioned Photography

Use when paid stock cannot meet the required specificity: Swiss/European home context, quiet premium mood, child agency, parent visibility without monitoring, and exact crop needs.

Required before use:

- Written usage rights for STOA public website and marketing surfaces.
- Model releases for all identifiable people, especially children.
- Parent/guardian releases for minors.
- Location/property release if needed.
- Delivery of uncropped master files and approved crop variants.
- Written confirmation that no school endorsement, trademark, or private information appears.

### Path C: Temporary Public Approval Of Current Preview Assets

Use only if the business chooses speed over final visual strength.

Required before use:

- Explicit written approval that current Hero and Parent Confidence images are temporary public assets.
- Follow-up replacement task with owner and deadline.
- No claim that they are final brand photography.

## Source Guardrails

| Source Type | Allowed | Not Allowed |
|-------------|---------|-------------|
| iStock/Getty | Link-only review before purchase; purchased final assets after approval | Watermarked previews in repo or UI |
| Pexels/Unsplash | Source-clear preview/candidate use when license and creator are recorded | Final public use if image feels generic, mismatched, or endorsement-risky |
| Commissioned | Final public use with releases and usage rights | Any image without model/minor releases |
| AI-generated | Non-identifiable texture/detail only | Identifiable family or child faces |

## Recommendation

Commissioned photography is the cleanest path for final public use because the required mood is specific: high-end Swiss/European family learning, not generic homework stock.

Paid iStock/Getty review is still worthwhile as a lower-cost fallback before commissioning.

# Practice Parent Report Integration

Parents should see learning activity, not disconnected product modules.

## Learning Activity Summary

The parent report should combine:

- questions asked,
- practice lessons completed,
- mistakes reviewed,
- teacher support requested,
- current practice path,
- recommended next topic.

## Copy Rules

Use supportive wording:

> Anna is practicing equations and asked for help on two-step problems. She is becoming more confident with one-step equations and could benefit from reviewing systems next.

Avoid:

- failed,
- weak,
- behind,
- ranking language,
- blame language.

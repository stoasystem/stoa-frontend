# Linear System Lessons

## Unit Goal

Students understand that a system solution is a pair of values that makes both equations true.

## Lessons

1. What is a system of equations?
2. Solving by substitution
3. Solving by elimination
4. Checking the solution

## Skills

- Test an ordered pair in both equations.
- Replace one variable using a known expression.
- Add equations when terms cancel.
- Substitute the found value back to get the second variable.
- Check both equations before confirming the solution.

## Demo Boundary

Use small whole numbers and short systems. Avoid fractions, graphing-heavy systems, and multi-page algebra.

# Practice-to-Chat CTA Rules

## Wrong Answer

Primary feedback actions:

- Show hint
- Explain this step
- Try again

Copy:

> Need help with this step?

## After Hint

Learning Chat CTA:

> Explain this step

The CTA should open Learning Chat with Practice context attached.

## Lesson Result

Result actions:

- Continue Practice
- Review mistakes
- Review with Learning Chat

## CTA Hierarchy

Practice keeps the student in the lesson first. Learning Chat appears when explanation is useful. Teacher support appears later.

Do not show all possible support actions with equal weight at the same time.

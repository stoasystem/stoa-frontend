# Practice UI Guidelines

## Visual Direction

Practice Path should feel calm, academic, and premium. It should use STOA's existing warm paper, burgundy, charcoal, and restrained card surfaces.

The memorable visual idea is a guided study path: ordered learning steps, measured progress, and clear support options.

## Allowed Gamification

- Study streak.
- Daily goal.
- Progress points.
- Lesson completion.
- Gentle badges.
- Mistakes review.
- Attempts.

These should read as learning signals, not entertainment mechanics.

## Avoid

- Bright cartoon green/red palettes.
- Mascots, shop, gems, public leaderboards, or reward economy.
- Punitive hearts or lives.
- Loud celebration animation.
- Sound effects.
- Copy that makes mistakes feel like failure.

## Feedback Treatment

Correct feedback should be clear and understated.

Incorrect feedback should use `Not quite`, offer a hint, and allow retry before stronger support actions.

When escalation is needed, labels should be:

- `Explain this step`
- `Ask a teacher`

Avoid `Ask AI`.

## Layout Rules

- Keep the primary lesson interaction stable in size so answer feedback does not shift the whole page.
- Use native buttons and forms for challenge controls.
- Do not rely on color alone for correct/incorrect state.
- Keep German, French, and Italian button labels from overflowing on mobile.
- Keep page sections unframed where possible; use cards for repeated lesson nodes, summaries, and challenge panels.

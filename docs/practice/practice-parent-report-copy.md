# Practice Parent Report Copy

Parent copy should translate practice activity into calm learning signals.

## Fields

- Current practice path
- Lessons completed
- Topics practiced
- Mistakes reviewed
- Practice streak
- Suggested next topic

## Tone Rules

Use:

- currently practicing
- could benefit from more practice
- review
- next topic
- confident with

Avoid:

- failed
- weak
- behind
- poor score
- struggling badly

## Example

This week, Anna completed 3 short practice lessons on equations. She is confident with one-step equations and could benefit from more practice with two-step equations and simple systems.

German guidance:

Ihr Kind übt derzeit Gleichungen und könnte besonders bei Aufgaben mit mehreren Schritten weiter profitieren.

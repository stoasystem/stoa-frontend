# Practice as Learning Chat Entry

## Positioning

Practice Path helps students start learning through short guided exercises, then brings them into Learning Chat when they need a clearer explanation.

Practice is not the whole product. It is one learning entry into the STOA support system.

## Product Hierarchy

1. Practice gives students a place to start.
2. Learning Chat explains when they get stuck.
3. Teachers support when more guidance is needed.
4. Parents see how learning develops.

## Forbidden Language

Do not describe STOA as:

- A game platform.
- A Duolingo clone.
- A place where students learn only by playing.
- A replacement for Learning Chat.
- A replacement for teachers.

## Recommended Language

- Start with practice. Ask for an explanation when you get stuck.
- Practice helps you begin. Learning Chat helps you understand.
- Teacher support stays available when the explanation is not enough.
- Parents see the complete learning activity.

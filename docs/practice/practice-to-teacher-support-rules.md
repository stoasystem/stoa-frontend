# Practice-to-Teacher Support Rules

## Principle

Professional teacher support is an escalation layer, not the first response to a practice mistake.

## When to Show

Show Ask a teacher after:

- The student has made repeated incorrect attempts.
- The student has viewed a hint.
- The student still needs a clearer explanation.

## Recommended Copy

> This step may need a clearer explanation.

> Ask a teacher after trying the hint and Learning Chat explanation.

## Tutor Context

Teacher requests from Practice should include:

- Source: Practice lesson
- Topic
- Question
- Student answer
- Attempts
- Hint viewed
- Learning Chat explanation requested

## Avoid

- The game failed.
- The student failed this step.
- The system could not teach this.
- Human support required.

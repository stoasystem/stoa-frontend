# Practice Dashboard Integration

The Student Dashboard is the main learning entry center.

## Entry Cards

- Continue Practice: current path, next lesson, daily goal, streak, recent mistakes.
- Ask a question: specific homework or stuck step entry into Learning Chat.
- Recent learning activity: previous questions and practice signals.
- Recent mistakes: direct review path.
- Teacher support status: escalation state when help has been requested.

## Ordering

Practice should appear before Chat as the recommended next action when the student has an active lesson. Chat remains visible as the direct question path.

## Product Relationship

Practice and Chat are not competing features:

- Practice is proactive learning.
- Learning Chat is contextual explanation when a student has a specific question.
- Teacher support is human escalation after guided help is insufficient.

# Practice Demo Scenario

Recommended duration: 3-5 minutes.

## Route

1. Student Dashboard -> Continue Practice.
2. Practice Overview -> Mathematics: Equations.
3. Subject Path -> Linear equations in one variable.
4. Lesson -> Solving equations in two steps.
5. Student answers one challenge correctly.
6. Student answers the next challenge incorrectly.
7. Feedback appears with `Not quite`.
8. Student opens `Show hint`.
9. Student retries or clicks `Explain this step`.
10. Learning Assistant explanation guides the next step.
11. Lesson completes.
12. Parent Report shows Practice summary.

## Demo Message

STOA is not only for asking questions after a student gets stuck. It can also guide short active practice. When the student misses a step, the product gives a hint first, then a guided explanation, and only escalates to professional teacher support when needed.

## Operator Notes

Use the current Mathematics / Equations demo topic only. Do not open Physics or unrelated math topics during the Phase 28 demo.

# Challenge Difficulty Rules

Each lesson should move through a small difficulty ladder.

## Levels

1. Recognition: identify the equation type, first operation, or useful method.
2. Simple calculation: perform one clear step.
3. Step selection: choose or order the next solving steps.
4. Full solution: solve a short equation or system.
5. Review or word problem: connect the answer back to meaning.

## Rules

- First challenge should be easy enough to build confidence.
- Each challenge should test one core idea.
- Avoid long arithmetic.
- Avoid nested brackets beyond one simple layer.
- Avoid heavy fractions.
- Avoid advanced quadratic methods.
- Keep each lesson demoable in roughly one minute.

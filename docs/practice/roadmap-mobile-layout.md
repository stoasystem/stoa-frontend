# Roadmap Mobile Layout

Mobile layout must prioritize readability over decorative path movement.

## Rules

- Use a simple vertical path.
- Keep lesson nodes full-width within the content column.
- Avoid horizontal zig-zag offsets on small screens.
- Keep connector lines short and aligned with the current node stack.
- Allow long German, French, and Italian strings to wrap.
- Do not shrink font sizes based on viewport width.

## Desktop Difference

Desktop can use light left/right offsets to create a path feeling. Offsets should stay restrained so the roadmap still reads like a premium education interface.

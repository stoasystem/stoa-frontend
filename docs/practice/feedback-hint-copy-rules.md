# Feedback And Hint Copy Rules

## Correct Feedback

Correct feedback should name the useful step.

Good:

- Correct. Subtracting 5 first leaves the term with x ready to divide.
- Correct. +y and -y cancel when the equations are added.

Avoid:

- Correct.
- Great job!

## Incorrect Feedback

Incorrect feedback should be calm and directional.

Good:

- Not quite. Look at the +5 first: what operation would remove it?
- Not quite. The pair must work in both equations.

Avoid:

- Wrong.
- The answer is x = 5.

## Hints

Hints should:

- give the next step
- stay short
- fit lower-secondary students
- avoid final-answer reveal

Good:

- First remove the +5. Then divide by 3.
- Replace y with x + 1 in the second equation.

Avoid:

- x = 5.
- Use the quadratic formula.

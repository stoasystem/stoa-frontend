# Linear Equation Lessons

## Unit Goal

Students understand that solving a linear equation means keeping both sides balanced while isolating the unknown.

## Lessons

1. One-step equations
2. Solving equations in two steps
3. Equations with brackets
4. Word problems with linear equations

## Skills

- Undo addition or subtraction.
- Undo multiplication or division.
- Remove outside operations before solving inside brackets.
- Translate a short story into an equation.
- Check whether the answer makes both sides equal.

## Demo Challenge Pattern

- Recognition: identify the first operation to undo.
- Simple calculation: solve for the value.
- Step selection: order the solving steps.
- Review: explain what the unknown represents.

Hints should point to the next operation, not reveal the final value.

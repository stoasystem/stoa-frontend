# Equation Demo Content Package

Phase 28 selects one Mathematics demo package for the general Practice Path: Equations.

This is frontend demo content, not the final Practice Path scope. Practice Path is intended to become a general middle-school and high-school learning challenge system across subjects and topics.

The goal of this package is to show a clear, stable, education-oriented path that can be demonstrated in 3-5 minutes.

## Product Scope

Practice Path is broader than equations.

Canonical hierarchy:

```text
Practice Path -> Subject -> Grade level -> Topic -> Unit -> Lesson -> Challenge
```

Current demo hierarchy:

```text
Practice Path -> Mathematics -> Lower Secondary -> Equations -> Unit -> Lesson -> Challenge
```

## Target Learner

Lower secondary / Grade 8 level.

Lessons should:

- use short prompts
- test one idea at a time
- avoid advanced algebra
- make the next step visible
- support hint-first recovery after mistakes

## Units

1. Linear equations in one variable
2. Quadratic equations
3. Linear systems in two variables

## Out Of Scope For This Demo Package

- Implemented Physics practice
- Implemented Geometry, probability, statistics, and functions
- large problem bank
- adaptive learning
- real course database
- production backend
- high-school advanced quadratic methods

Phase 28 should improve demo quality, not expand implemented content breadth. It should not be interpreted as saying Practice Path equals equations.

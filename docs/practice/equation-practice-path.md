# Equation Practice Path

Phase 28 narrows the Practice demo to one Mathematics path: Equations.

This is frontend demo content, not a full curriculum library. The goal is to show a clear, stable, education-oriented path that can be demonstrated in 3-5 minutes.

## Target Learner

Lower secondary / Grade 8 level.

Lessons should:

- use short prompts
- test one idea at a time
- avoid advanced algebra
- make the next step visible
- support hint-first recovery after mistakes

## Units

1. Linear equations in one variable
2. Quadratic equations
3. Linear systems in two variables

## Out Of Scope

- Physics practice
- Geometry, probability, statistics, and functions
- large problem bank
- adaptive learning
- real course database
- production backend
- high-school advanced quadratic methods

Phase 28 should improve demo quality, not expand product breadth.

# 一张星图装下全部学科

2026-10-02，星图设计验收第一轮（stoasystem/stoa-frontend#117）决定：学生只有一张星图，所有学科以**星系**的形式排在同一片左右首尾相接的天空里，不再「一个学科一张图、每次只看一张」（#72、#13 原先的形态）。原因是学科之间存在前置关系，例如物理的光学需要数学的三角函数，按学科切开的图让这种联系不可见。

## Considered Options

- **一学科一张图，用切换器换图**（原方案）：每张图更简单、「这个学科点亮了多少」一目了然，但跨学科前置无处可画，学生看到的是互不相干的几块知识。否决。
- **一片天空，只显示在修的学科**：又回到分割，被跨学科前置用到的知识区凭空消失。否决。没修的学科照样出现，整片调暗。

## Consequences

- 学科切换器改为「飞到那个星系」，标题与点亮计数跟随视野中心所在的星系。
- 信息架构与路由（`/map/:subjectId/...`，#13）、后端星图读模型（stoa-backend#59，原按 subject 出图）与前置关系存储（stoa-backend#56）都要能表达跨学科的星图；这些在前端设计验收（#114）通过后，于 #3 处理。
- 连线必须分层露出、按与学生此刻的相关程度定明暗，否则一张装下全部学科的全景会变成一团乱线（#117 结论 D1–D3）。

# Site Layout After Practice Integration

Phase 29 organizes STOA around one learning platform instead of separate tools.

## Public Website

- Homepage
- How it works
- For Parents
- Pricing
- Contact
- Login
- Start learning

Homepage copy should use `Start learning` as the broad entry point. It can explain that students practice step by step or ask a question when stuck, but it should not split the first viewport into competing Practice and Chat CTAs.

## Student App

- Dashboard
- Practice
- Learning Chat
- History
- Profile

Dashboard is the learning entry center.

## Parent App

- Overview
- Child Report
- Practice Progress
- Teacher Support Records
- Billing
- Contact

Parent surfaces should frame Practice and Chat as learning activity.

## Tutor App

- Requests
- Request Detail
- Availability
- Support

Practice-originated teacher requests should expose the topic and challenge context when available.

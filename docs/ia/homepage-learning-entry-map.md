# Homepage Learning Entry Map

## First Screen

Hero communicates STOA's full platform value:

- learning support
- clear explanations
- professional teacher support
- parent visibility

Primary CTA: Start Learning

## Practice Entry

Practice appears after the Hero as a direct student action.

Message:

```text
Start with a short equation challenge.
If you get stuck, Learning Chat helps you understand the step.
```

CTA: Start Practice

## How STOA Works

This section explains the platform hierarchy:

1. Students practise or ask a question.
2. Learning Chat explains the unclear step.
3. Professional Teacher Support can join when needed.
4. Parents see the learning activity and next focus.

## Downstream Surfaces

| Surface | Role in Flow |
|---------|--------------|
| `/practice` | Student starts or continues short equation practice |
| `/chat` | Explanation center when a step is unclear |
| `/tutor` | Professional support queue with Practice context |
| `/parent` | Parent visibility over Practice, Chat, and support activity |

## IA Rule

Practice should be visible enough to start the learning funnel, but it should not become a top-level public navbar item or the only product story without user-testing evidence.

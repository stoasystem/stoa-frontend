# Phase 12 Learning Profile UI

The advanced learning profile is a frontend presentation of future learning intelligence data.

Routes:

- `/students/:studentId/learning-profile`
- `/organization/students/:studentId/learning-profile`

Displays:

- Student info and active subjects
- Weak topics
- Strong topics
- Recent learning history
- Usage summary
- Teacher help history
- Recommended actions

Out of scope:

- Real AI learning profile generation
- Raw chat transcript analysis in the browser
- Long-term learning warehouse design

The browser renders precomputed mock/API response data only.

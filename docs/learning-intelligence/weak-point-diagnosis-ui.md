# Phase 12 Weak-Point Diagnosis UI

The weak-point diagnosis UI presents mock diagnosis results for product demonstration.

Route:

- `/students/:studentId/diagnosis`

Displays:

- Diagnosis summary
- Weak points and severity
- Evidence list
- Suggested practice
- Teacher help recommendation
- Parent explanation

Out of scope:

- Real diagnosis engine
- Model prompt orchestration
- Automated scoring from raw student content

The frontend should never imply that the demo diagnosis is production AI output.

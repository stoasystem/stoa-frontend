## Branch Criteria

Create `release/launch-candidate-1` or `release/stoa-learning-platform-lc1` only after:

- Build passed.
- Core demo flow passed.
- P0 bugs = 0.
- Copy lock complete.
- Design lock complete.
- Translation lock complete.
- API contract lock complete.
- Known issues accepted.

## Branch Rules

- Bug fixes only after branch creation.
- No new features.
- No large visual redesign.
- No API contract change without frontend, demo backend, docs, and demo-flow retest.
- All changes must be reflected in release notes or known issues.

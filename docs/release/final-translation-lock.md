# Final Translation Lock

## Supported Languages

- English (`en`)
- German (`de`)
- French (`fr`)
- Italian (`it`)

## Covered Surfaces

- Homepage.
- Register.
- Login.
- Chat.
- Parent report.
- Tutor requests.
- Pricing.
- Billing.
- Contact.
- Footer.

## Lock Rules

- Do not update one language alone unless the change is non-user-visible or language-specific typo repair.
- Do not reintroduce user-facing `AI`, `demo`, `mock`, provider, or development wording.
- German headings must stay concise and should not become long translated sentences in large typography.
- French apostrophes must remain correct and render safely.
- Italian CTA labels must remain natural and fit mobile buttons.
- All CTA changes require mobile fit checks.

## Approval Checklist

- [ ] English checked.
- [ ] German checked.
- [ ] French checked.
- [ ] Italian checked.
- [ ] German long-heading risk checked.
- [ ] French apostrophes checked.
- [ ] Italian CTA fit checked.
- [ ] Language switcher checked.

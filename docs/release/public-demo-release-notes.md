# Public Demo Release Notes

**Release name:** STOA Learning Platform public demo release
**Date:** 2026-05-26

## Internal Release Notes

### Purpose

This release converts the Phase 22 launch candidate into a public demo release by fixing required launch-candidate approval issues, preserving release locks, rerunning final smoke checks, and preparing deployment/presentation handoff.

### Main Flows Included

- Homepage and public learning-positioning pages.
- Registration and login.
- Student chat with Learning Assistant response.
- Professional teacher support request.
- Tutor request queue, detail, note/status handling.
- Parent dashboard and child report.
- Pricing and billing-interest path.
- Contact form submission.
- Admin operations overview.

### Supported Roles

- Student.
- Parent.
- Tutor.
- Admin.

### Supported Languages

- English.
- German.
- French.
- Italian.

### Internal Backend Note

The release is supported by the public demo API environment for presentation and stakeholder validation. It is not the final production backend, production database, production payment system, or AWS production architecture.

### Verification

- Phase 128: final approval intake and bug triage completed.
- Phase 129: approved blocker fixes verified and release locks preserved.
- Phase 130: final demo rerun, multilingual smoke, responsive smoke, accessibility smoke, and build passed.

### Known Limitations

- Payment collection is not live.
- Public registration remains controlled by environment flag.
- Manual Safari, Firefox, Edge, Mobile Safari, Android Chrome, screen-reader, and native-speaker checks remain recommended before broader rollout.
- Real backend and AWS integration remain Phase 24+ handoff work.

## External Release Notes

### Purpose

STOA Learning Platform is ready for external preview conversations with families, teachers, investors, and partners.

### What Is Included

- A clear homepage explaining STOA's learning support model.
- Student question flow with structured learning support.
- Professional teacher support handoff.
- Parent visibility through child learning reports.
- Tutor request workflow.
- Pricing overview.
- Contact path for follow-up.
- Four-language core experience: English, German, French, and Italian.

### Intended Audience

- Families evaluating STOA.
- Teachers or tutors reviewing the support workflow.
- Investors reviewing the product direction.
- Potential partners exploring collaboration.

### Current Limitations

- This preview is for demonstration and feedback, not general public signup.
- Payment collection is not active.
- Some operational views are intended for product conversations, not day-to-day customer use.

### Contact

For questions or follow-up, use the STOA contact page or the release owner.

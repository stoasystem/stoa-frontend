# Tutor Practice Context Test Task Sheet

## Goal

Check whether a tutor can understand a student's Practice-origin support request.

## Tasks

1. Log in with the tutor test account provided by the facilitator.
2. Open the request list.
3. Find a request that originated from Practice or is described by the facilitator as a Practice request.
4. Open the request detail.
5. Identify the subject and topic.
6. Identify the lesson or challenge if shown.
7. Identify the student's recent answer if shown.
8. Decide what explanation you would give first.
9. Mark or describe the request as resolved when instructed.

## Review Questions

- Is the student context sufficient?
- Can you see where the student struggled?
- Is the request workflow clear?
- Would this help you support students more efficiently?
- What context would you need before responding?

## Success Signal

The tutor should not need a long chat transcript to understand the current stuck step. The request should make the topic, challenge, and student confusion clear enough to start helping.

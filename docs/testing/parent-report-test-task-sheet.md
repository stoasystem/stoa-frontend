# Parent Report Test Task Sheet

## Goal

Review whether the parent report makes the child's learning activity understandable.

## Tasks

1. Log in with the parent test account provided by the facilitator.
2. Open the parent overview.
3. Open the child's learning report.
4. Find the learning activity summary.
5. Identify what the child practised.
6. Find the number of questions asked or the question activity area.
7. Find whether teacher support was requested.
8. Find the recommended next step.
9. Explain, in your own words, what the child worked on recently.
10. Explain what you would want the child to do next.

## Think-Aloud Prompts

Say what you are thinking when:

- You first see the report.
- You look for Practice activity.
- You look for Learning Chat or question activity.
- You read the recommendation.

## Completion Questions

- Could you understand what your child practised?
- Was the report useful?
- Did teacher support increase trust?
- Would this help you follow learning at home?
- What information is missing?

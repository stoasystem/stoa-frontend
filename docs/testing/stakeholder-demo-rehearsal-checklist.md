# Stakeholder Demo Rehearsal Checklist

Use this before presenting the Phase 30 demo externally.

## Three-Minute Check

- [ ] Dashboard opens.
- [ ] Continue Practice is visible.
- [ ] A Practice challenge can be shown.
- [ ] Incorrect answer shows feedback and hint.
- [ ] `Explain this step` opens Learning Chat with context.
- [ ] Parent Report summary can be shown.

## Ten-Minute Check

- [ ] Homepage positioning is clear.
- [ ] Student Dashboard explains Practice and questions as connected entries.
- [ ] Practice lesson can show one correct answer.
- [ ] Practice lesson can show one incorrect answer.
- [ ] Hint appears before full explanation.
- [ ] Learning Chat context card appears.
- [ ] Back to lesson works or can be explained.
- [ ] Teacher support appears as escalation, not first response.
- [ ] Parent Report shows learning activity and recommendation.

## Fifteen-Minute Stakeholder Check

- [ ] Product positioning is clear.
- [ ] Student value is clear.
- [ ] Parent value is clear.
- [ ] Teacher support value is clear.
- [ ] Equation-only curriculum boundary is stated.
- [ ] Future curriculum and backend requirements are stated without overclaiming.
- [ ] Pricing/growth direction is connected to combined value, not isolated tools.

## Failure Handling

If any critical step fails, switch to the short script and explain the intended flow using the curriculum package. Record the failure as a demo reliability issue for the next backlog.

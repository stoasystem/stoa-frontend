# Student Practice Test Task Sheet

## Goal

Try the STOA Practice Path flow as a student. The current demo topic is Mathematics / Equations.

This is not a math test. We want to learn whether the product makes the next step clear.

## Tasks

1. Log in with the student test account provided by the facilitator.
2. Open the Student Dashboard.
3. Find the next practice action.
4. Click `Continue Practice`.
5. Open the current Mathematics / Equations demo topic.
6. Start the linear equations lesson.
7. Answer the first challenge correctly if possible.
8. On the next challenge, intentionally enter an incorrect answer.
9. Read the feedback.
10. Show the hint.
11. Try to explain what the hint is asking you to do.
12. Click `Explain this step`.
13. In Learning Chat, read the practice context and explanation.
14. Use `Back to lesson`.
15. Complete or exit the lesson when instructed by the facilitator.

## Think-Aloud Prompts

Say what you are thinking when:

- You choose where to click from the dashboard.
- You see feedback after an incorrect answer.
- You read the hint.
- You decide whether to open Learning Chat.
- You return to the lesson.

## Completion Questions

- Did you know what to do next?
- Was the hint helpful?
- Did Learning Chat explain the step you were stuck on?
- Would this help when doing homework?
- When would you ask a teacher?

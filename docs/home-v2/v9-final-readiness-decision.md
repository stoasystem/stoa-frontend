# Home V2 v9 Final Readiness Decision

**Date:** 2026-07-07  
**Route:** `/home-v2`

## Decision

**Ready for switch-over planning.**

This is not a route-switch approval and not a public launch sign-off. It means the concrete v8 blockers have been reduced enough to prepare a dedicated switch-over stage.

## Summary

- Current `/` remains unchanged.
- FR mobile body overflow is fixed.
- FR/IT long Hero titles are constrained without mid-word breaks.
- Mobile Hero image presentation is less dominant and reads as a controlled frame.
- Desktop navigation labels are more visible.
- `/privacy` and `/terms` no longer present themselves as visibly unfinished draft/review pages.
- Basic default and route-level metadata are implemented.
- Current images are recorded as temporary-public-approved for preview and planning, not final-public-approved.
- Future canonical, sitemap, old-home preservation, and rollback steps are documented.

## Remaining Conditions

- A separate route switch stage must explicitly approve any `/home-v2` to `/` replacement.
- Hero and Parent Confidence imagery still need final licensed or commissioned replacement before broad public marketing, unless the owner explicitly accepts temporary use for a controlled launch.
- Legal pages still need qualified legal review before public reliance.
- Production canonical URL, sitemap policy, language alternate policy, monitoring checklist, and rollback commit plan need to be finalized during switch-over.

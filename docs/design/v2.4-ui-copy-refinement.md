# v2.4 UI Copy Refinement

## Product Chain

Use this student-facing sequence when naming cross-feature flows:

1. Continue Learning / Practice Path
2. Practice Library
3. Learning Assistant / Upload a Question
4. Tutor Support
5. Online Classroom

## Preferred Terms

| Use | Avoid |
|-----|-------|
| Practice Library | Question Bank in student UI |
| Upload a Question | Photo Solver, AI Solver |
| Take Photo | Scan and Solve |
| Attach File / Attach PDF | Upload homework for automatic solving |
| Ask Learning Assistant | AI teacher |
| Ask a Tutor | Ask a teacher in student support CTAs |
| Tutor support requested | Teacher support requested |
| Tutor joined | Tutor joined by text |
| Start Live Classroom | Start video classroom |
| Live classroom completed | Meeting ended |

## Upload Trust Copy

Uploads are learning context only. Do not imply OCR, handwriting recognition, image understanding, automatic solutions, grading, or parent review. Modal and inline upload surfaces should show supported formats, maximum file size, privacy note, attached files, remove/retry actions, and Ask Learning Assistant.

## Classroom Copy

Online Classroom should read as learning support with context, materials, notes, and next steps. Avoid provider-specific or implementation-specific claims such as Zoom, real stream, recording, screen share, mock video, or mock classroom.

## Parent And Tutor Boundaries

Tutor surfaces should expose source, context, materials, suggested focus, and clear next action labels. Parent surfaces should summarize learning support and classroom visibility without observer, recording, attendance, or classroom-control claims.

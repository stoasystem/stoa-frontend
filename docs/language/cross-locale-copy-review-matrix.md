## Approval Rules

- Literal match should normally be `No`.
- Meaning aligned must be `Yes`.
- Tone aligned must be `Yes`.
- UI length OK must be `Yes` after visual QA.
- Any copy containing user-facing `demo`, `mock`, `test account`, `Codex`, `human backup`, `teacher backup`, `buy now`, or `what we are selling` is not approved.

# English Copy Rules

English STOA copy should feel calm, precise, premium, and education-oriented. It should not sound like generic SaaS, aggressive sales copy, or a technical assistant demo.

## Tone

English copy should feel:

- clear
- composed
- trustworthy
- practical
- family-aware
- education-centered

Avoid hype, automation-first language, and conversion pressure.

## Headline Rules

Prefer short, confident headings:

- Learn with clarity.
- Guided learning support.
- Progress families can understand.
- Professional teacher support when it is needed.

Avoid:

- AI-powered learning automation.
- Buy AI tutoring now.
- What we are selling.
- Human backup for homework questions.

## CTA Rules

Prefer:

- Start learning
- Start
- Ask a question
- Ask a teacher
- View report
- Choose a plan
- Continue

Avoid:

- Buy now
- Unlock automation
- Request human backup
- Try demo account

## Product Terminology

Use:

- Learning Assistant
- explanation
- professional teacher support
- families
- students
- parents
- teachers
- learning progress

Avoid user-facing:

- AI tutor
- AI response
- chatbot
- bot
- human backup
- teacher backup
- customers where `families`, `parents`, `students`, or `teachers` is more precise

## Layout Rules

English usually fits the default layout, but copy should still avoid oversized marketing slogans. Keep hero titles between 3 and 7 words. Buttons should remain action-focused and should not carry explanatory text.

## Page Guidance

Homepage:
Use education value language, not technology positioning.

Register:
Explain role choice as account setup, not onboarding mechanics.

Chat:
Use short student-friendly actions and clear error states.

Parent Report:
Use supportive progress language. Do not create anxiety.

Pricing and Billing:
Use `Choose a plan` and value language. Avoid purchase pressure.

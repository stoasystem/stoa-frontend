# STOA Copy Style Guide

## Voice

STOA copy should be clear, calm, helpful, trustworthy, and education-oriented.

Prefer:

- concrete learning outcomes
- clear next actions
- family confidence and transparency
- professional teacher support
- honest demo wording only where users need it

Avoid:

- hype-driven technology language
- promises of perfect answers
- implying teachers are replaced
- fear-based parent messaging
- cold SaaS wording on student or parent pages
- sales-heavy phrases such as "buy now" or "what we are selling"

## Replacement Rules

| Avoid | Use |
| --- | --- |
| AI support | Learning support |
| AI answer | Explanation |
| AI tutor | Learning Assistant |
| AI is thinking | The Learning Assistant is preparing an explanation |
| Ask AI | Ask your Learning Assistant |
| Human backup | Professional teacher support |
| Teacher backup | Professional teacher support |
| What we are selling | The value for families |
| Buy a plan | Choose a plan |
| Customers | Families, parents, students, or teachers |

## Page Guidance

Homepage:
Explain the product as a learning support path, not a technology pitch.

Chat:
Students should see simple action language: ask a question, receive an explanation, ask a teacher if needed.

Parents:
Emphasize learning progress, patterns, and confidence without requiring parents to read every chat.

Teachers:
Emphasize professional context and support workflow. Do not imply teachers are backup systems.

Pricing:
Use "choose a plan" and "the value for families" language. Avoid developer or quota-enforcement explanations in customer-facing FAQ copy.

## Phase 17 Locale-Specific Copy

Natural local copy is more important than literal translation.

Allowed:

- different sentence structures per language
- German stacked hero titles
- shorter German CTA labels
- French sentences that read elegantly but still fit the UI
- Italian copy that is warmer and conversational while staying clear

Not allowed:

- changing product meaning by locale
- adding claims in one language that do not exist in the others
- hiding overlong copy with global font-size reductions
- introducing sales-heavy copy in pricing or billing
- describing teachers as backup systems

## Headline Length Guidance

| Locale | Guidance |
| --- | --- |
| English | 3-7 words for hero titles. Keep calm and direct. |
| German | 2-5 words, or stacked short lines. Avoid long compounds in display type. |
| French | 3-7 words. Elegant is fine; abstract noun stacks are not. |
| Italian | 3-7 words. Warm and natural, but not vague. |

Large headings should create rhythm. Explanations belong in subtitles and body copy.

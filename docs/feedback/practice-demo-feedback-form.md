## Student Questions

- Did you know what to do next?
- Was the hint helpful?
- Did the explanation help you understand the step?
- Would you use this when doing homework?
- When would you ask a teacher?

## Parent Questions

- Could you understand what your child practised?
- Was the report useful?
- Did the teacher support option increase trust?
- Would this help you follow learning at home?
- What information is missing?

## Tutor Questions

- Is the student context sufficient?
- Can you see where the student struggled?
- Is the request workflow clear?
- Would this help you support students more efficiently?
- What additional context would you need?

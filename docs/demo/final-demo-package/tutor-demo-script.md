# Tutor Demo Script

## Goal

Show that professional teacher support remains organized and visible inside the learning process.

## Flow

1. Sign in as `tutor@test.com`.
2. Open `/tutor/requests`.
3. Show pending, in-progress, and resolved requests.
4. Open one request detail.
5. Review student context and conversation history.
6. Add or reference a tutor note if available.
7. Update request status.
8. Explain how STOA helps organize where teacher attention is needed.

## Tutor Message

Professional teacher support remains part of the learning process. STOA helps organize when and where a teacher is needed.

## Avoid

- Saying teachers are replaced.
- Deep admin analytics.
- Payment or parent-sales language.
- Unfinished advanced operations.

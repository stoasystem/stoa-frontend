# Student Demo Script

## Goal

Show that STOA is simple, direct, and useful when a student is stuck.

## Flow

1. Sign in as `student@test.com`.
2. Open `/dashboard`.
   - Show the next action briefly.
3. Open `/chat`.
4. Ask or open a question.
   - Keep the question short and concrete.
5. Show the explanation.
   - Emphasize step-by-step clarity.
6. Ask a follow-up or show the student can continue.
7. Trigger or review a teacher-help request.
8. Open `/learning-history`.
   - Show that prior learning is saved for review.

## Student Message

Ask the question you actually have. If the explanation is not clear enough, you can continue asking or request professional teacher support.

## Avoid

- Product strategy.
- Pricing details.
- Admin or parent-only routes.
- Long explanations of the backend.

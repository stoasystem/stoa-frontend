# Parent Demo Script

## Goal

Show trust, clarity, and learning visibility for a parent.

## Flow

1. Open `/`.
   - Say: STOA helps students ask questions when they are stuck and gives parents clearer visibility into progress.
2. Open `/chat` as `student@test.com`.
   - Show a clear student question and explanation.
   - Show that the student can continue asking follow-up questions.
3. Show teacher-help request.
   - Say: Professional teacher support remains part of the learning process when an explanation is not enough.
4. Sign in as `parent@test.com`.
5. Open `/parent`.
   - Show linked child overview.
6. Open `/parent/children/user-student/report`.
   - Show questions asked, progress, weak topics, recommendations, and next steps.
7. Open `/pricing`.
   - Keep pricing short and practical.
8. Open `/contact`.
   - Show that a parent can ask STOA for help.

## Parent Message

STOA is not replacing teachers. STOA gives students immediate learning support and gives parents clearer visibility into learning progress.

## Avoid

- Admin pages.
- Complex tutor operations.
- Internal demo/backend wording.
- Overpromising diagnosis, grades, or guaranteed improvement.

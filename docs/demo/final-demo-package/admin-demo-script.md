# Admin Demo Script

## Goal

Show operational visibility without presenting unfinished admin areas as launch-ready production systems.

## Flow

1. Sign in as `admin@test.com`.
2. Open `/admin`.
   - Show high-level operational overview.
3. Open `/admin/analytics`.
   - Show usage summary and demand signals.
4. Show teacher-help request visibility if available in the admin route set.
5. Open support ticket admin view where available.
6. Reference contact request visibility through the demo backend/admin operations surface.
7. Close with known limitations and next-stage backlog.

## Admin Message

The launch candidate demonstrates operational visibility for demos and review. Production analytics, support operations, and admin workflows remain backend/operations-owned future work.

## Avoid

- Deep unfinished internal pages.
- Production SLA or monitoring claims.
- Complex CRM, BI, or financial reporting claims.
- Raw backend/database details.

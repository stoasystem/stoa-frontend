# Practice as Learning Chat Entry Demo

## Demo Story

Practice is not the final product by itself. It is a low-friction learning entry. Deeper support happens through Learning Chat and professional teacher support.

## Flow

1. Homepage shows STOA's learning hierarchy.
2. Student enters Dashboard.
3. Student chooses Continue Practice.
4. Student gets stuck on an equation step.
5. Student asks for explanation in Learning Chat.
6. Learning Chat explains the step with Practice context.
7. Student returns to the lesson.
8. Student requests teacher support if still confused.
9. Parent sees the complete learning activity.
10. Tutor sees Practice context when joining a request.

## Presenter Notes

Use this phrasing:

> Practice helps the student start. Learning Chat helps the student understand. Teacher support keeps the student from staying stuck. Parent Report makes the process visible.

Avoid this phrasing:

> STOA is a learning game.

> Practice replaces tutoring.

> Students learn only by playing.

## 3-Minute Version

Show homepage, dashboard, one Practice mistake, Explain this step, Learning Chat context, Back to lesson, and Parent Report learning activity.

## 10-Minute Version

Add teacher escalation and Tutor Request Detail practice context.

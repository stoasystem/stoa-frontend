# Practice Integrated Demo Flow

Recommended Phase 29 demo route:

1. Homepage.
2. Student login.
3. Dashboard.
4. Continue Practice.
5. Start a lesson from the intro screen.
6. Solve one equation correctly.
7. Answer one challenge incorrectly.
8. Show hint.
9. Click `Explain this step`.
10. Learning Chat opens with the practice context card.
11. Return with `Back to lesson`.
12. Complete the lesson.
13. Parent opens report.
14. Parent sees unified learning activity and recommendation.

## Demo Message

STOA is useful before and after a student has a clear question. Practice helps the student find the stuck step. Learning Chat explains that step. Teacher support is available only when guided help is not enough. Parents see the overall learning activity.

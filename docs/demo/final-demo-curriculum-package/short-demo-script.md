# Three-Minute Demo Script

Use this for quick conversations where the audience needs the product idea, not the full walkthrough.

## Sequence

1. Student Dashboard
2. Practice challenge
3. Incorrect answer
4. Hint
5. `Explain this step`
6. Learning Chat context
7. Parent Report summary

## Talk Track

`STOA is useful even before a student knows what to ask. The student starts with a short Practice Path lesson in the current Mathematics / Equations demo topic.`

Show the Practice lesson.

`When the student makes a mistake, STOA first gives a hint. It does not simply reveal the answer.`

Show the hint.

`If the student still needs help, Explain this step opens Learning Chat with the exact question and context.`

Show the context card.

`The student can then return to the lesson. Later, the parent can see what was practised, where help was needed, and what the next useful step is.`

Show Parent Report.

## Point To Land

`Practice reveals the stuck step. Learning Chat explains it. Teacher support is available if needed. Parents get a clear learning summary.`

# Fifteen-Minute Stakeholder Demo Script

Use this for investors, partners, school leaders, or strategic reviewers.

## Structure

| Segment | Time | Message |
|---------|------|---------|
| Product positioning | 2 minutes | STOA connects active practice, guided explanation, teacher support, and parent visibility. |
| Student active practice | 3 minutes | Students can learn even when they do not start with a specific question. |
| Learning Chat explanation | 3 minutes | Contextual support helps students understand the current step. |
| Teacher support | 2 minutes | Human help appears when it adds value. |
| Parent visibility | 2 minutes | Parents see the learning process in understandable language. |
| Growth and roadmap | 3 minutes | The current demo proves the flow; future work expands curriculum and backend persistence. |

## Positioning Opening

`STOA is a guided learning platform. The student can practise proactively, ask for explanation when stuck, and receive teacher support when guided help is not enough. Parents see the learning activity in a clear report.`

## Student Value

Show Dashboard and Practice.

`The student can begin with a recommended lesson instead of needing to formulate a question first. That lowers the barrier to learning.`

## Learning Assistant Value

Show mistake, hint, and Learning Chat.

`The explanation is tied to the exact practice step. This is more useful than a generic chat box because the system already knows the topic, prompt, and recent answer.`

## Teacher Support Value

Show teacher-support escalation.

`Teacher support is not hidden, but it is also not pushed too early. STOA uses guided help first, then brings in a professional teacher when more explanation is needed.`

## Parent Value

Show Parent Report.

`Parents do not need raw logs. They need to know what the student practised, where support was useful, and what should happen next.`

## Roadmap Boundary

Say:

`The current demo is intentionally focused on equations. That lets us prove the learning loop clearly. Future work should expand the curriculum, persist learning data in the backend, and run structured external testing before broad rollout.`

## Pricing and Growth Direction

Say:

`The product story supports a clear value ladder: guided practice, contextual explanations, professional teacher support, and parent visibility. Later pricing and growth work should be built around that combined value, not around isolated tools.`

# External Demo Language Checklist

Use this checklist before presenting STOA externally.

## Say

- Learning Assistant
- Learning Chat
- Practice Path
- professional teacher support
- guided explanation
- parent learning summary
- final equation demo
- future backend integration

## Avoid

- AI answer bot
- fake data
- mock backend
- provider
- prompt harness
- debug mode
- internal model
- production-ready curriculum
- teacher replacement

## Product Story Check

Before each demo, confirm the script lands these ideas:

- Students can practise proactively.
- Mistakes lead to hints before full explanation.
- Learning Chat receives the practice context.
- Teacher support appears when guided help is not enough.
- Parents see a supportive learning summary.
- The equation demo is focused by design.

## External Q&A Guardrails

If asked whether the curriculum is complete:

`The current demo is intentionally focused on equations. It is designed to show the complete learning loop before broader curriculum expansion.`

If asked whether teacher support is automated:

`Learning Assistant provides guided explanations first. Professional teacher support is available when students need more help.`

If asked whether this is production backend ready:

`The frontend demo defines the product flow and future backend requirements. Production persistence and operations are planned as follow-up work.`

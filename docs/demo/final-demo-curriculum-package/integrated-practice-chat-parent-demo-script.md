# Integrated Practice, Chat, and Parent Demo Script

Use this script for a 10-minute external demo.

## Goal

Show how STOA connects practice, guided explanations, teacher support, and parent visibility into one learning flow.

## Timing

| Segment | Time | Purpose |
|---------|------|---------|
| Homepage | 1 minute | Explain STOA's learning positioning. |
| Student Dashboard | 1 minute | Show the student's learning entry point. |
| Practice Path | 2 minutes | Show active equation practice. |
| Mistake and hint | 1 minute | Show low-pressure support. |
| Learning Chat | 2 minutes | Show guided explanation with context. |
| Teacher support | 1 minute | Show escalation when more help is needed. |
| Parent Report | 2 minutes | Show learning visibility and next step. |

## Script

### 1. Homepage

Say:

`STOA helps students practise step by step and ask for explanations when they get stuck. The goal is not to replace teachers, but to make the learning path clearer before, during, and after support.`

Show the learning entry copy that explains practice and questions as two parts of the same learning flow.

### 2. Student Dashboard

Say:

`The student does not need to start with a perfect question. The dashboard gives a next action: continue practice, or open Learning Chat for a specific question.`

Click `Continue Practice`.

### 3. Practice Path

Say:

`The demo curriculum focuses on equations. That lets us show a complete learning loop in a controlled topic.`

Open the linear equations lesson.

### 4. Correct Answer

Answer the first challenge correctly.

Say:

`The feedback is short and specific. It confirms the reasoning step, not just the result.`

### 5. Mistake and Hint

Answer the next challenge incorrectly.

Say:

`When the student gets stuck, STOA does not jump straight to a full answer. It gives a hint first and invites another try.`

Show the hint.

### 6. Explain This Step

Click `Explain this step`.

Say:

`Now Learning Chat opens with the practice context. The student does not have to retype the equation or explain where they got stuck.`

Show the context card and guided explanation.

### 7. Back to Lesson

Return to the lesson.

Say:

`The student can come back to practice after the explanation, so the support remains part of the learning flow.`

### 8. Teacher Support

Show where teacher support appears after continued confusion.

Say:

`Professional teacher support is available when guided help is not enough. It is an escalation, not the first response.`

### 9. Parent Report

Open the parent report.

Say:

`Parents see the overall learning activity: what was practised, where help was requested, and what the next useful step is. The language is supportive, not punitive.`

## Close

Say:

`This demo shows STOA as a connected learning platform: students practise, get guided explanations, escalate to a teacher when needed, and parents understand the learning process.`

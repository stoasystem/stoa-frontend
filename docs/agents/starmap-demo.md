# 漫天知识星空演示（#48 / #109 / #76）

默认 **1000 颗知识星 / 15 个逻辑主题**。知识星铺在整个二维视野中，宽阔的高密度区域与分散星点相融，亮雾带有不规则暗纹。上下和四角保留星光，没有独立圆形光团或窄带轮廓。

视觉参考：[ESO 银河中心宽视野照片](https://www.eso.org/public/images/eso0949l/)。仅借鉴细密星光、亮云和暗尘的层次；不复制全景照片上下大片黑色的构图。场景采用原生 Canvas，照片只用于本地验收页的对照。

## 本地预览

启动：`npm run dev -- --host 127.0.0.1 --port 5184`。
打开 `/src/dev/starmap.html?host=ask&path=/map/math`，无须登录或后端。`host=ask` 复用布局模拟器，不挂实际 Ask，不请求课程数据；布局中的通知组件仍可能尝试请求本地后端。

- `&points=500` / `&points=2000` 比较密度，`points=10` 用于小夹具调试。
- 默认关闭模糊聚合；`&foveation=on` 可比较聚合效果，`?bench=1` 仍默认开启聚合。
- `&relations=fixture` 显示固定的前置关系；`&longNames=1` 检查四语长名称。这两个选项仅由独立开发 host 的 props 注入，正式路由不会从查询参数启用假关系。
- `.codex-screenshots/starmap-visual/index.html` 是被 Git 忽略的本地验收页，有 10 / 500 / 2000 × 桌面 1440×900 / 手机 390×844 的同夹具前后对照（均开启聚合）。默认 1000 的示例关闭聚合。

## 数据与交互

- 四语名称为占位文本，课程与技能为空；学习颜色、推荐与复习标记为固定演示样本，提示条明确说明。
- 默认前置关系为空，章节不会打开真实课程，复习入口为“即将推出”。
- 拖动、缩放、点进主题与星卡片可用。全景按最近真实知识星判断主题，避免主题的包围圆重叠导致误选。
- 全景主题名只在悬停或键盘聚焦时出现；没有安全位置则隐藏，完整名称始终保留在并行 DOM，键盘焦点用按实际宽高放置的名称框。德 / 英 / 法 / 意 × 桌面 / 手机的 8 组长名称焦点框都在可见区域内。
- 数学与物理复用同一分布，德语展示空图；上次学科按账号保存在本地。

## 绘制与验证

- `demoGalaxyPositions` 是演示布局，保持 ID、主题归属与状态不变，知识星在整个二维视野采样，主题仅用于逻辑归属，不形成独立光团；星尘与蓝紫 / 暖金辉光按实际知识星坐标缓存，和知识星一起拖动、缩放、转为手机纵向布局。
- 全景知识星为 1.15–2.1 px，放大后 glyph 上限 40 px。装饰星尘不计入学习数据或点击目标。
- 标签整框必须更近所属主题并避开语义连线。短间隙为弧形桥，放大后屏外关联目标有方向与名称。
- 模糊图块使用 64 / 128 / 256 分辨率缓存，缩小保留高分辨率；任何星状态变化都使所属图块失效。辉光在坐标或颜色状态变化时重画，不逐帧生成。缓存画布四边各留 128 px，云层在地图边缘自然消退，不产生矩形裁切。
- 知识辉光透明度上限 0.14，视野微光上限 0.04；以白色星尘饱和叠加作为对比度上界，对比度测试仍要求文字 4.5:1、锁定控件与语义连线 3:1。锁定环保留 42%；未改变锁定状态的图形语义。
- 全量 2032 项测试、lint、typecheck、API 契约（213 后端路径 / 162 调用）、翻译守卫、CSS 与 Canvas 对比度、release 54 项、publisher 4 项、生产 build 通过。

真实内容仍等待 stoa-backend#59（#56/#57/#60），接入点为 `useStarMap.ts`。本演示不验证后端响应契约，不作为 #48 的真实数据验收。用户视觉验收和真实 iOS/Android 性能验收尚未完成，不能据此关闭 #109 / #76 / #44。

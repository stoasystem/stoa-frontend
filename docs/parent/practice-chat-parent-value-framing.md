# Practice and Chat Parent Value Framing

Parent-facing communication should explain learning activity, not tool usage.

## Core Parent Message

`Your child is building confidence through short practice, guided explanations, and support when needed. The report helps you understand what happened and what the next useful step is.`

## What To Express

- What the child practised.
- Which topic is becoming more confident.
- Which topic still benefits from practice.
- Whether Learning Chat helped with a specific step.
- Whether professional teacher support was requested.
- What the next recommended action is.

## Recommended Language

Use:

- `building confidence`
- `still practising`
- `could benefit from reviewing`
- `next helpful step`
- `asked for guidance on`
- `received support with`

Avoid:

- `failed`
- `weak`
- `bad at`
- `behind`
- `struggling badly`
- `made too many mistakes`

## Example Summary

`This week, Anna practised equations and asked for help on two-step problems. She is becoming more confident with one-step equations and could benefit from reviewing systems of equations next.`

## Why This Matters

Parents need clarity and trust. A supportive summary helps them understand the learning process without turning mistakes into pressure.

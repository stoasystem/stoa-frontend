# Learning Report Integration Guidance

The Parent Report should present Practice and Learning Chat as one learning activity.

## Recommended Section

`Learning activity this week`

## Content Blocks

1. Summary paragraph
2. Practice lessons completed
3. Questions asked
4. Mistakes reviewed
5. Teacher support requested
6. Topics practised
7. Recommended next step

## Suggested Layout

Use:

- Summary paragraph for interpretation
- Small metric cards for quick scanning
- Topic list for context
- Recommendation card for the next step

Avoid:

- Dense charts before the parent understands the story
- Ranking language
- Failure counts as the primary framing
- Tool-separated sections that make Practice and Chat look unrelated

## Example Data Story

`Anna completed 3 short practice lessons on equations, reviewed 2 mistakes, and asked for help with one two-step equation. The next helpful step is to practise checking answers after solving.`

## Future Data Dependencies

A production report will need persisted:

- Practice lessons completed
- Challenges attempted
- Mistakes reviewed
- Hint usage
- Learning Chat context
- Teacher support requests
- Recommended next topic

# Launch Checklist

## Before Launch

- [ ] CI passes.
- [ ] `npm run build` passes.
- [ ] E2E smoke tests pass.
- [ ] Manual QA core flows pass.
- [ ] No open P0 bugs.
- [ ] No open P1 bugs without workaround.
- [ ] Environment variables reviewed.
- [ ] Monitoring active.
- [ ] Analytics active.
- [ ] Support channel active.
- [ ] Privacy and terms are reachable.
- [ ] Rollback plan reviewed.
- [ ] Public registration setting confirmed.
- [ ] Payment and mock checkout flags confirmed.

## Core Flow QA

- [ ] Student dashboard and chat.
- [ ] Parent dashboard and report.
- [ ] Tutor queue and request detail.
- [ ] Admin usage, feedback, and help requests.
- [ ] Pricing page.
- [ ] Billing page.
- [ ] Virtual checkout success and cancel.

# Post-Launch Monitoring

## First 72 Hours

Monitor:

- Login failures.
- Chat send failures.
- Streaming errors.
- File upload errors.
- Teacher-help request failures.
- Parent report load failures.
- Checkout errors if payment is enabled.
- Frontend runtime errors.

## First Week Daily Check

- Error monitoring.
- Feedback.
- Support requests.
- Analytics usage.
- Tutor help queue.
- Parent report views.
- Pricing and billing events.

# Linear Equation Demo

## Unit

Linear equations in one variable

## Learning Goal

The student learns that solving a linear equation means keeping both sides balanced while isolating `x`.

## Demo Lessons

| Lesson | Core Skill | Representative Challenge |
|--------|------------|--------------------------|
| One-step equations | Undo a single addition, subtraction, multiplication, or division | Solve `x + 7 = 12`. |
| Solving equations in two steps | Remove the constant term, then divide or multiply | Solve `3x + 5 = 20`. |
| Equations with brackets | Simplify or divide before isolating `x` | Solve `2(x + 3) = 14`. |
| Word problems with linear equations | Translate a short situation into an equation | A number plus 7 is 12. Find the number. |

## Hint Style

Hints should guide the next operation without giving the final answer.

Example:

`Try subtracting 5 from both sides first.`

Avoid:

`The answer is x = 5.`

## Feedback Purpose

Correct feedback reinforces why the step worked.

Incorrect feedback points to the next action and invites a retry.

## Demo Role

This unit is the safest entry point for the main external demo because it is easy to understand in a few seconds. It is the best place to show a correct answer, a mistake, a hint, and `Explain this step`.

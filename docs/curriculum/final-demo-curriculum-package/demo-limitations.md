# Demo Limitations

The final demo curriculum package is intentionally focused.

## What Is Real in the Demo

- The product flow is coherent: Practice, hint, Learning Chat, teacher support, and Parent Report.
- The equation path has a clear lower-secondary learning progression.
- The challenge feedback and hints model the intended learning behavior.
- The parent summary shows the intended learning visibility.

## What Is Not Included

- Complete Mathematics curriculum
- Geometry, probability, physics, trigonometry, calculus, or advanced functions
- Production course database
- Curriculum authoring CMS
- Real adaptive learning algorithm
- Production teacher scheduling
- Production feedback/research tooling
- Formal backend persistence for every Practice event

## How To Explain This Externally

Use this framing:

`This demo focuses on equations so we can show the complete learning loop clearly. It is not meant to represent the full future curriculum.`

## Risk To Avoid

Do not present the demo as a finished course product. Present it as a stable curriculum slice that proves the learning flow and gives a clear basis for external feedback.

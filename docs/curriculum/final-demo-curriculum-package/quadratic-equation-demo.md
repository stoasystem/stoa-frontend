# Quadratic Equation Demo

## Unit

Quadratic equations

## Learning Goal

The student learns that simple quadratic equations can sometimes be solved by factoring and using the zero-product idea.

## Demo Lessons

| Lesson | Core Skill | Representative Challenge |
|--------|------------|--------------------------|
| Recognizing quadratic equations | Identify an equation containing `x^2` | Which option is quadratic? |
| Factoring simple quadratics | Find two numbers that multiply and add to the target values | Factor `x^2 - 5x + 6`. |
| Solving factored quadratics | Set each factor equal to zero | Solve `(x - 2)(x - 3) = 0`. |
| Checking two solutions | Substitute both possible solutions back | Check whether `x = 2` and `x = 3` work. |

## Hint Style

Hints should identify the reasoning pattern, not solve the factorization outright.

Example:

`Find two numbers that multiply to 6 and add to -5.`

## Scope Boundary

This demo does not introduce:

- Quadratic formula derivation
- Discriminant cases
- Complex roots
- Vertex form
- Calculus

## Demo Role

This unit shows that STOA can handle a slightly more advanced equation topic while still keeping explanations age-appropriate and step-based.

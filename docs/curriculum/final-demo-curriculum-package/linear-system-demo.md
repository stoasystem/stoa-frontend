# Linear System Demo

## Unit

Linear systems in two variables

## Learning Goal

The student learns that a solution to a system must satisfy both equations.

## Demo Lessons

| Lesson | Core Skill | Representative Challenge |
|--------|------------|--------------------------|
| What is a system? | Recognize that two equations must be true together | Which pair solves `x + y = 7` and `x - y = 1`? |
| Solving by substitution | Replace one variable expression in the other equation | Solve `y = x + 1`, `x + y = 9`. |
| Solving by elimination | Add or subtract equations to remove a variable | Solve `x + y = 8`, `x - y = 2`. |
| Checking the solution | Substitute the pair into both equations | Check whether `x = 5, y = 3` works. |

## Hint Style

Hints should identify the next method step.

Example:

`Add the two equations. The y terms cancel out.`

## Demo Role

This unit is useful for showing the value of context in teacher support. A tutor can see the topic, method, student answer, and attempt count instead of receiving a vague help request.

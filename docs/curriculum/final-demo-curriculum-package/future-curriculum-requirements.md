# Future Curriculum Requirements

Phase 30 does not build the full curriculum system. It defines what future work should consider after the equation demo is tested externally.

## Content Expansion

Future curriculum work should define:

- Grade bands
- Subject sequence
- Topic prerequisites
- Lesson objectives
- Challenge difficulty rules
- Hint and feedback review rules
- Teacher review workflow for sensitive or ambiguous content

## Curriculum Quality

Each future topic should include:

- Clear learning outcome
- 3-5 demo challenges for prototype validation
- Misconception notes
- Directional hints
- Correct feedback
- Incorrect feedback
- Parent-readable topic summary

## Expansion Order

Recommended sequence:

1. More equation lessons
2. Functions connected to equations
3. Geometry foundations
4. Probability and statistics basics
5. Physics only after the math demo is stable

## Backend Handoff

Future backend work should support persistent curriculum entities, lesson progress, mistake history, Practice-to-Chat context, teacher request context, and parent reporting data. It should not be inferred from the current frontend mock data alone.

# Practice to Teacher Support Flow

Teacher support is an escalation path, not the first response.

## Trigger Pattern

Teacher support should appear after:

- The student has answered incorrectly more than once,
- The student has used a hint,
- The student has asked Learning Chat to explain the step,
- Or the student still says they do not understand.

## Demo Flow

1. Student gets stuck in Practice.
2. STOA gives feedback and a hint.
3. Student asks Learning Chat for a guided explanation.
4. If confusion remains, STOA asks whether a teacher should explain the step.
5. Teacher request carries the Practice context.

## Teacher Context

The request should include:

- Source: Practice
- Subject and topic
- Lesson and challenge
- Student answer
- Attempts
- Whether hints or Learning Chat were used

## Demo Message

Professional teacher support increases trust because it is available when guided support is not enough, while the first response remains low-pressure and student-led.

# Parent Report Learning Summary

The Parent Report should explain learning activity, not separate tools.

## What Parents Should Understand

Parents should be able to answer:

- What did my child practise?
- Which topic is becoming more confident?
- Where did my child need support?
- Did Learning Chat help with a specific step?
- Was teacher support needed?
- What is the next useful practice topic?

## Recommended Structure

1. Summary paragraph
2. Small metric cards
3. Topics practised
4. Mistakes reviewed
5. Recommended next step

## Tone

Use supportive language:

`Your child is building confidence with one-step equations and is still practising multi-step problems.`

Avoid anxiety language:

`Your child failed many challenges.`

## Demo Message

Parent visibility is not surveillance. It helps a parent understand the learning process and see when guided help or teacher support adds value.

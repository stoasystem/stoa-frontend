# Equation Path Summary

The final demo content package is locked to equations.

This lock applies to the demo package only. Practice Path itself is a general middle-school and high-school learning challenge system that should remain subject-agnostic and topic-agnostic.

## Path

Subject: Mathematics

Demo topic: Equations

Grade level: Lower secondary

Primary skill: Solving equations through clear, reversible steps.

## Units

| Unit | Focus | Demo Purpose |
|------|-------|--------------|
| Linear equations in one variable | Isolate `x` with one-step, two-step, bracket, and word-problem examples | Shows the most accessible Practice flow and hint-first support. |
| Quadratic equations | Recognize simple quadratics, factor simple expressions, solve factored quadratics, and check two solutions | Shows that STOA can support multi-answer reasoning without moving into high-school-only complexity. |
| Linear systems in two variables | Understand solution pairs, substitution, elimination, and checking both equations | Shows how a student can get stuck on a method step and move into Learning Chat. |

## Excluded From This Demo Package

The demo package does not include:

- Geometry
- Probability
- Trigonometry
- Calculus
- Advanced functions
- University-level mathematics
- A broad Mathematics course library

These exclusions do not limit the long-term Practice Path scope.

## Demo Quality Principle

The demo package is intentionally narrow. A focused equation demo is more credible than a broad but shallow curriculum library because it can show a clean learning progression, useful hints, guided explanation, teacher escalation, and parent visibility in one short session.

# Phase 12 Advanced Analytics UI

Advanced analytics is a frontend dashboard that renders aggregated mock/API contract data.

Routes:

- `/admin/advanced-analytics`
- `/organization/analytics`

Displays:

- Weekly active students
- Weekly active parents
- Questions by subject
- Teacher help request rate
- File upload rate
- Parent report view rate
- Conversion funnel
- Retention cohorts
- Churn-risk placeholder data

Out of scope:

- Production analytics backend
- Data warehouse
- Raw event aggregation in the browser
- Churn prediction model

The browser should render already-aggregated values only.

## 五个方向

| 方案 | 视觉构成 | 优势 | 取舍 |
|---|---|---|---|
| 01 学院编辑 | 米白、酒红、衬线、细线、数学符号 | 延续品牌；开放版面，降低卡片堆叠 | 气质较成熟 |
| 02 瑞士极简 | 中性浅灰、黑色按钮、紧凑网格、无衬线 | 高频登录清晰；无图片资源 | 情感表达较少 |
| 03 温暖学习桌 | 鼠尾草绿、暖白纸卡、现有学习照片 | 对学生家庭亲和；图片复用 | 主按钮绿需确认品牌接受度 |
| 04 深色建筑 | 墨绿、石色表单、拱廊线条 | 区分度高；表单保持高对比 | 与现有浅色产品衔接需设计 |
| 05 轻快几何 | 暖黄、酒红、几何拼贴、轻量硬阴影 | 年轻有活力；纯 CSS 图形 | 更大胆，需确认目标年龄气质 |

推荐优先比较 01 与 03；若目标是登录效率，选 02。所有方向均只保留邮箱/密码路径，不添加未经证实的 SSO、用户数量、认证徽章或实时学习进度。

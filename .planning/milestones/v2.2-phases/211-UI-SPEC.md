# Phase 211 UI Spec

## Localization Contract

- English, German, French, and Italian copy covers upload actions, statuses, validation errors, preview labels, dropzone copy, privacy reminder, and Chat handoff context.
- Long localized strings must wrap in panels and cards without forcing horizontal overflow.

## Accessibility Contract

- Upload controls use buttons or labeled inputs.
- Status and error text uses status/alert/live-region behavior.
- Modal supports keyboard close and focus return.
- Remove/retry action labels include filenames.

# Phase 207 UI Spec

## Interaction Contract

- File attach and photo capture are icon-led button actions with accessible text.
- Dropzone supports pointer drag/drop and a keyboard Browse files action.
- Preview cards show thumbnail or file card, filename, size, status, and action buttons.
- Error messages use alert behavior; status changes use status/live-region behavior.
- Modal receives focus on open, supports Escape, visible close, and completion action.

## Visual Contract

- Components remain compact and task-adjacent.
- Preview cards use stable dimensions so upload status changes do not resize the composer or learning panel.
- Copy avoids OCR, auto-solve, storage, teacher grading, parent review, and moderation claims.

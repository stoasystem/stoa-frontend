# Phase 209 UI Spec

## Interaction Contract

- Home page upload is a secondary CTA below the primary Question Bank discovery controls.
- Question Session upload appears after feedback/help context and does not compete with answer submission.
- Completed uploads open Chat with a source-specific starter context.

## Context Contract

Handoff metadata includes source, source label, optional session/question IDs, attachment IDs, filenames, sizes, kinds, and uploaded URLs when present.

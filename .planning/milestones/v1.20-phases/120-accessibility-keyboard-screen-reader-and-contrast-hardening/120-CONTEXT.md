# Phase 120 Context

## Goal

Harden accessibility, keyboard navigation, screen-reader support, and contrast for the release-facing STOA surfaces without expanding product scope.

## Priority Surfaces

- Homepage
- Login
- Register
- Chat
- Parent dashboard and report
- Tutor requests
- Pricing
- Billing
- Contact
- Support

## Constraints

- Keep changes targeted.
- Avoid redesigning the visual system.
- Document limitations when local browser automation is blocked.
- Preserve Phase 119 brand/contact implementation.

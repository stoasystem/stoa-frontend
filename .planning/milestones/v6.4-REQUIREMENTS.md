# Requirements: STOA Frontend v6.4

**Defined:** 2026-07-06
**Core Value:** Hero and Parent Confidence photography must be source-clear, Swiss/European-compatible, emotionally credible, and refined enough for a high-end Swiss parent homepage before `/home-v2` can be prepared to replace `/`.

## v6.4 Requirements

### Photography Direction

- [x] **PHOTO-01**: Hero and Parent Confidence each have a final photography acceptance contract covering audience fit, emotional tone, composition, crop needs, license needs, and rejection criteria.
- [x] **PHOTO-02**: The acceptance contract explicitly rejects AI-generated identifiable faces, wrong-market family signals, bright generic stock interiors, surveillance-like parent postures, and school-endorsement implications.

### Targeted Source Search

- [x] **SRC-01**: Targeted free-source search is run against section-specific briefs for Pexels and Unsplash, with no broad unscored downloads.
- [x] **SRC-02**: Targeted paid-source search is documented for iStock or comparable paid stock, with link-only candidates and purchase rationale.
- [x] **SRC-03**: Every candidate records source URL, license/source URL, creator/vendor where available, asset role, AI status, Swiss-parent fit, emotional fit, crop risk, endorsement risk, and download/commit decision.
- [x] **SRC-04**: Only source-clear free candidates intended for preview/candidate use may be downloaded or committed; paid previews and watermarked images remain link-only.

### Crop And Page Fit

- [x] **CROP-01**: Shortlisted Hero candidates are tested against the current desktop and mobile Hero frame requirements.
- [x] **CROP-02**: Shortlisted Parent candidates are tested against the current Parent Confidence frame and note-overlay requirements.
- [x] **CROP-03**: Candidate comparisons document why the current image remains, is replaced, or is blocked pending paid/commissioned approval.

### Preview Implementation

- [x] **IMPL-01**: If a clearly stronger source-clear free candidate is found, it is optimized into the preview asset set and implemented in `/home-v2` only.
- [x] **IMPL-02**: If no stronger free candidate is found, `/home-v2` keeps the current preview image while the paid/commissioned recommendation is documented.
- [x] **IMPL-03**: Any implemented asset change includes responsive screenshot verification and keeps `/` unchanged.

### Approval Handoff

- [x] **APP-01**: v6.4 ends with a clear final asset recommendation: approved preview asset, paid purchase candidate, commissioned shoot brief, or blocked.
- [x] **APP-02**: The handoff states whether Home V2 can move to switch-over preparation or must solve final photography first.

## Future Requirements

| Requirement | Reason Deferred |
|-------------|-----------------|
| Purchasing iStock or commissioned photography | Requires explicit budget and license approval. |
| Replacing `/` with `/home-v2` | Requires a separate switch-over milestone. |
| Runtime FR/IT enablement | Not part of Hero/Parent photography approval. |
| Full SEO/sitemap/canonical/rollback work | Belongs to switch-over preparation. |

## Out of Scope

| Item | Reason |
|------|--------|
| Replacing `/` | v6.4 only approves or blocks final photography. |
| AI-generated identifiable family or child faces | Not acceptable for the main public family trust signal. |
| Downloading paid/watermarked previews into the repo | Legal and quality risk. |
| Broad redesign of Home V2 IA, copy, or product behavior | v6.4 is final photography approval only. |
| Backend, auth, registration, quota, or payment behavior | Not related to homepage photography. |

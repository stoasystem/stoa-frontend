# v6.1 Roadmap: Home V2 Parent Confidence Redesign

## Milestone Summary

Redesign Parent Confidence into a warm, emotionally clear section about parents staying close without taking over.

## Phases

### Phase 6.1.1: Section Audit And Copy Contract

Goal: Lock the section's emotional promise and remove dashboard-like wording.

Tasks:

- Audit current `HomeV2ParentConfidence` layout, image, overlays, and EN/DE/FR/IT copy.
- Define final title/body/proof-note copy direction.
- Identify copy that should be removed or softened.

Deliverables:

- Copy contract for title, body, proof note, and image caption behavior.
- Updated i18n key plan if keys need restructuring.

### Phase 6.1.2: Visual Structure Redesign

Goal: Replace the current multi-pill overlay with a warmer image-plus-note composition.

Tasks:

- Design the new image/proof layout.
- Define desktop, tablet, and mobile proportions.
- Keep double-bezel physical depth without nested-card clutter.

Deliverables:

- Component layout plan for `HomeV2ParentConfidence`.
- Responsive visual rules for image and note placement.

### Phase 6.1.3: Implementation

Goal: Implement the new Parent Confidence section.

Tasks:

- Update `HomeV2ParentConfidence.tsx`.
- Update `home-v2-premium.css` only where scoped styling is needed.
- Update EN/DE/FR/IT `homeV2` copy.

Deliverables:

- Working `/home-v2` Parent Confidence section.
- No changes to `/` homepage.

### Phase 6.1.4: Verification And Polish

Goal: Validate visual quality and responsive behavior.

Tasks:

- Run lint/build/Home V2 E2E.
- Capture desktop, tablet/narrow, and mobile screenshots.
- Fix any overflow, image dominance, text density, or overlap.

Deliverables:

- Verification notes.
- Final commit for v6.1.

## Dependencies

- Depends on v4.0 Home V2 preview route and component namespace.
- Uses existing Home V2 image pool unless final image sourcing is separately approved.

## Done Definition

- Parent Confidence reads as emotional reassurance, not feature explanation.
- One quiet proof/note surface replaces the current pill stack.
- Responsive screenshots pass visual inspection.
- Required commands pass.

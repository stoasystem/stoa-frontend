# Requirements: STOA Frontend v6.5

**Defined:** 2026-07-06
**Core Value:** Home V2 final photography must have a clear procurement and commissioning package so the next visual step can be executed without diluting the Swiss high-end parent positioning or creating licensing risk.

## v6.5 Requirements

### Procurement Strategy

- [x] **PROC-01**: Define the decision path between paid stock purchase, commissioned photography, and temporary public approval of preview assets.
- [x] **PROC-02**: Document license and release checks for iStock/Getty, Pexels, Unsplash, and commissioned photography before any public use.
- [x] **PROC-03**: Keep paid previews, watermarked images, and unlicensed candidate files out of the repository.

### Art Direction

- [x] **ART-01**: Translate the Home V2 visual direction into a final Hero photography art direction brief.
- [x] **ART-02**: Translate the Parent Confidence section into a final photography art direction brief focused on transparency without monitoring.
- [x] **ART-03**: Define high-end image qualities: natural light, restraint, negative space, child agency, quiet European home context, and crop-safe composition.

### Paid Stock Review

- [x] **STOCK-01**: Provide paid stock search routes and query variants for iStock/Getty review.
- [x] **STOCK-02**: Provide a paid-stock candidate scoring template that captures fit, licensing, release status, crop risk, endorsement risk, and purchase recommendation.
- [x] **STOCK-03**: Define rejection rules for paid stock that looks generic, overly commercial, culturally mismatched, surveillance-like, school-endorsed, or visually noisy.

### Commissioned Shoot Package

- [x] **SHOT-01**: Provide a commissioning brief for Hero and Parent Confidence photography.
- [x] **SHOT-02**: Define shot list, wardrobe, location, model/release expectations, lighting, props, composition, and delivery formats.
- [x] **SHOT-03**: Define usage-right requirements and required deliverables for future WebP/AVIF/frontend implementation.

### Approval Workflow

- [x] **APPROVAL-01**: Define a practical approval workflow from candidate intake to final image approval.
- [x] **APPROVAL-02**: State that Home V2 should not switch `/` until final public imagery is purchased, commissioned, or explicitly accepted as temporary.
- [x] **APPROVAL-03**: Provide a handoff checklist for the future implementation milestone.

## Future Requirements

| Requirement | Reason Deferred |
|-------------|-----------------|
| Purchasing paid stock | Requires user budget and explicit purchase approval. |
| Running a commissioned shoot | Requires vendor/model/location coordination outside the repo. |
| Downloading final licensed images | Requires purchase or commissioned delivery first. |
| Optimizing final images into WebP/AVIF | Requires approved final source files. |
| Replacing `/` with `/home-v2` | Requires separate switch-over milestone after final asset approval. |

## Out of Scope

| Item | Reason |
|------|--------|
| Buying iStock/Getty assets | No explicit purchase approval yet. |
| Downloading watermarked paid previews | Legal and brand risk. |
| Replacing current preview images | v6.5 prepares procurement, not implementation. |
| Replacing `/` | Switch-over remains separate. |
| AI-generated identifiable family/child imagery | Rejected for final public family trust signal. |
| Broad redesign of `/home-v2` | v6.5 is asset procurement preparation only. |

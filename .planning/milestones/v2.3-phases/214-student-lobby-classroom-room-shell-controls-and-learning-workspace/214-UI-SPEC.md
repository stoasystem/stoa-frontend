# Phase 214 UI Spec

- Lobby should feel like preparation for a learning session, with context and device readiness visible before join.
- Room desktop layout should prioritize video context plus learning workspace; side panel should hold chat/materials/notes/participants.
- Room mobile layout should stack video/workspace before secondary panels.
- Controls need visible text labels for mute, camera, material sharing, whiteboard, chat, participants, and leave.
- Leave confirmation must distinguish student leave from tutor end-session semantics.

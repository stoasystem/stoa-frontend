# Phase 215 Plan

## Goal

Extend Learning Chat so teacher text help can escalate into a mock video classroom lobby while preserving learning context.

## Tasks

- Add teacher support stage state for requested, text active, video requested, and lobby ready.
- Add an escalation card after teacher help is requested.
- Let students mark tutor text as active and start a video classroom.
- Create an instant classroom session through the live classroom service.
- Navigate to `/classroom/sessions/:sessionId/lobby?source=chat`.

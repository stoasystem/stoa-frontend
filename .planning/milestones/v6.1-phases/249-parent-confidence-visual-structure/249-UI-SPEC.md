# Phase 249 UI Spec

## Interaction Contract

- No new click/tap behavior.
- Existing reveal motion remains.
- Note marker may breathe subtly; reduced-motion disables it.

## Visual Contract

- Use Editorial Luxury plus Editorial Split.
- Text and image stack on narrow screens.
- The note uses paper-like depth, inset line, soft highlight, and restrained warm light.
- No nested card clutter beyond the primary double-bezel frame and single proof note.

# Phase 250 UI Spec

## Interaction Contract

- Section remains passive and scroll-revealed.
- Parent note is visible and does not require hover or tap.

## Visual Contract

- Desktop: editorial split with copy left and image/note right.
- Tablet/mobile: stacked layout with protected top spacing below floating nav.
- The note marker breathes softly and uses reduced-motion handling.
- No pill-stack, dashboard, or monitoring UI remains.

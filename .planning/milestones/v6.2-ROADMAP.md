# v6.2 Roadmap: Home V2 Trust And Assurance Redesign

## Milestone Summary

Redesign the Trust section into a warm image-led assurance section with precise principles and Apple-like restraint.

## Phases

### Phase 6.2.1: Art Direction And Asset Decision

Goal: Lock the image direction before layout implementation.

Tasks:

- Review existing Home V2 image pool for fit.
- Define image acceptance criteria against the v6.2 requirements.
- Decide whether a placeholder is acceptable or whether paid/commissioned sourcing is required.

Deliverables:

- Image art direction note.
- Candidate/placeholder recommendation.
- Risk notes for endorsement, identity, and stock feel.

### Phase 6.2.2: Assurance Copy Contract

Goal: Define the assurance principles without slogan-heavy privacy or Swiss repetition.

Tasks:

- Draft title/body and 3-4 principle rows.
- Remove generic trust, privacy, compliance, AI, and feature-card language.
- Prepare EN/DE/FR/IT copy key plan.

Deliverables:

- Final copy contract for Trust/Assurance section.
- i18n update plan.

### Phase 6.2.3: Visual Structure Redesign

Goal: Replace the feature-card grid with an image-led assurance panel.

Tasks:

- Design desktop editorial composition.
- Design narrow/tablet and mobile stacking behavior.
- Define fine-line dividers, numbering, spacing, and text rhythm.

Deliverables:

- Component layout plan for `HomeV2TrustLayer`.
- Scoped CSS plan if needed.

### Phase 6.2.4: Implementation

Goal: Implement the new Trust/Assurance section.

Tasks:

- Update `HomeV2TrustLayer.tsx`.
- Update `home-v2-premium.css` only for scoped section styling.
- Update EN/DE/FR/IT `homeV2` resources.
- Insert approved placeholder or final candidate image.

Deliverables:

- Working `/home-v2` Trust/Assurance section.
- No changes to `/` homepage.

### Phase 6.2.5: Verification And Visual QA

Goal: Validate the section's high-end feel, responsive behavior, and claim discipline.

Tasks:

- Run lint/build/Home V2 E2E.
- Capture desktop, tablet/narrow, and mobile screenshots.
- Check that copy does not overuse "Swiss" or privacy claims.
- Check that image does not imply surveillance or endorsement.

Deliverables:

- Verification notes.
- Final commit for v6.2.

## Dependencies

- Depends on v4.0 Home V2 preview route and component namespace.
- Should follow v6.1 if Parent Confidence is redesigned first, so the two sections have clear contrast.

## Done Definition

- Trust/Assurance becomes image-led and editorial, not card-grid SaaS.
- A warm artistic image direction is documented and implemented with either an approved placeholder or final asset.
- Principle list communicates restraint and respect without loud privacy marketing.
- Required commands pass.

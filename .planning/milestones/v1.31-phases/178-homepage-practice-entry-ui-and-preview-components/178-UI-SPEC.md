# Phase 178 UI Spec: Homepage Practice Entry

**Created:** 2026-05-27

## Intent

Make Practice feel more immediate and inviting without making STOA look like a game. The section should feel like a premium guided-learning entry a student can click and a parent can trust.

## Layout

- Desktop: entry card on the left, preview panel on the right.
- Mobile: title, short explanation, CTA, preview, then full learning sequence.
- No nested card stack beyond one section container and contained preview cards.

## Visual Rules

- Use STOA burgundy, warm grey, paper/card, charcoal, and muted borders.
- Use subtle hover lift only for the entry card/CTA.
- Do not introduce bright green, mascots, confetti, XP, streak, hearts, gems, or leaderboard visuals.

## Interaction Rules

- Primary action: Start Practice.
- Secondary action: How it works / See how practice works.
- Preview content is explanatory; it should not behave like a partial lesson.

## Accessibility

- Section has a visible heading.
- Path preview uses ordered list semantics.
- Icon meaning is backed by text labels.
- Buttons allow wrapping and keep touch target height.
- Motion must be optional and reduced-motion safe.

## Issues Found And Fixed During Verification

- Browser login failed CORS preflight against the local backend; fixed with FastAPI CORS middleware for local dev/preview origins.
- Protected route direct navigation could redirect before current-user hydration; fixed by synchronously hydrating the stored token and rendering a loading state while `/auth/me` resolves.
- Student chat teacher-help request returned 404; fixed by adding student-facing `/teacher-help/request` create/get endpoints with ownership checks.
- E2E selectors were made stable for role landing pages, chat message scope, and tutor requests after smoke-test feedback.

## Residual Risks

- Staging URL and backend URL are documented placeholders until an actual hosting platform and backend staging environment are provisioned.
- CI currently runs lint and build; E2E is documented for local/staging runs and can be promoted into CI once a stable backend/preview target exists.
- Legal pages are MVP testing placeholders and require legal review before production launch.

## Decision

Milestone v1.7 satisfies the Phase 8 acceptance criteria and is ready to hand off to Phase 9: Production Readiness, Monitoring, and Pilot Launch.

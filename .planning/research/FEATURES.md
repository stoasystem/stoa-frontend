# Phase 19 Research: Features

## Milestone Type

Phase 19 is not a feature expansion milestone. It is a design-language translation and small-scope visual refinement milestone.

## Table Stakes

- Read-only audit of `/Users/zhdeng/newweb`, including pre/post `git status`.
- Documentation of company homepage design signals: color, typography, layout, components, images, and tone.
- Documentation of what the learning platform should share, adapt, and avoid copying.
- Design-token proposal for the learning platform.
- P0 page visual calibration:
  - Homepage.
  - Login.
  - Register/onboarding.
  - Chat.
  - Student dashboard.
  - Parent dashboard.
  - Parent report.
  - Pricing.
  - Billing.
- P1 basic calibration:
  - Tutor dashboard.
  - Tutor request detail.
  - Support.
  - Profile.
  - Learning history.
  - Referral.
- Token-only or light-touch P2 treatment:
  - Admin.
  - Organization.
  - Curriculum graph.
  - Advanced analytics.
  - Partnership pages.
- Visual compatibility QA against the target relationship: same brand family, different product surface.

## Differentiators

- Homepage/auth/report pages can lean closer to the main website's editorial feeling.
- Chat and dashboards should remain utilitarian, denser, and more app-like.
- Parent report should read like a premium education service report rather than a SaaS dashboard.
- Multilingual typography from Phase 17 must remain stable after visual changes.

## Anti-Features

- No direct component or CSS copying from `/Users/zhdeng/newweb`.
- No changes to `/Users/zhdeng/newweb`.
- No large page-structure redesign.
- No new business functionality.
- No new dependencies.
- No dashboard/chat conversion into marketing-style pages.

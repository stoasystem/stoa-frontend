# Research Summary — Phase 28

## Stack Additions

None. Phase 28 should use the existing React/Vite frontend, Practice service boundary, mock data, hooks, components, i18n, and browser smoke workflow.

## Feature Table Stakes

- Equation-only Practice demo path.
- Units for one-variable linear equations, quadratic equations, and two-variable linear systems.
- Lower-secondary difficulty with one idea per challenge.
- 3-5 challenges per lesson, ordered from recognition to guided calculation and review.
- Feedback and hints with teaching value.
- Hint-first Learning Assistant behavior.
- Parent report wording that is supportive and understandable.
- 3-5 minute demo scenario.

## Watch Outs

- Do not expand into a broad curriculum.
- Do not keep Physics as a competing visible demo path for Phase 28.
- Do not add backend/database/adaptive-learning systems.
- Do not let hints reveal final answers.
- Do not let quadratics drift into advanced formula/discriminant/complex-root content.
- Do not make parent copy sound punitive.

## Research Basis

Common Core Grade 8 emphasizes linear equations and systems of linear equations. High School Algebra standards include quadratic solving methods, but the Phase 28 demo should use only simple factoring and zero-product reasoning to stay age-appropriate and short. Khan Academy's algebra basics sequencing supports a practice path that moves from linear equations into systems and later quadratics/polynomials.

# Home V2 Premium Visual Redesign

## Goal

Respond to design review feedback that `/home-v2` still feels too close to the current homepage by making the preview route visibly distinct and closer to the `high-end-visual-design` direction.

## Scope

- Keep the current `/` homepage unchanged.
- Redesign only the Home V2 preview route and the layout/header behavior needed for that route.
- Apply an Editorial Luxury plus Z-Axis Cascade direction with macro whitespace, double-bezel surfaces, pill CTAs, custom motion, and stronger visual hierarchy.
- Avoid final image insertion, final copywriting, full animation choreography, and `/` switch-over.

## Acceptance

- `/home-v2` no longer reads as the same two-column/card system as the old homepage.
- Home V2 uses a distinct floating island navigation treatment.
- Major Home V2 sections use layered physical surfaces instead of flat generic cards.
- CTA treatment uses nested trailing-arrow pills.
- Lint and build pass.

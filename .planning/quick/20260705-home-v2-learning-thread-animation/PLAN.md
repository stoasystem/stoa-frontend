# Home V2 Learning Thread Animation

## Goal

Implement a restrained, warm Learning Thread animation for `/home-v2` that expresses a learning line being progressively lit by scroll, with subtle light/shadow vitality and a mobile-safe single-column timeline.

## Tasks

1. Add active-beat tracking to `HomeV2LearningThread` using `IntersectionObserver`.
2. Add scoped CSS for the timeline rail, lit progress, active nodes, card glow, and reduced-motion behavior.
3. Verify lint/build and run a focused `/home-v2` smoke check.

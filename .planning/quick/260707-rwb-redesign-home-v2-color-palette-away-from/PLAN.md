# Quick Task Plan: Redesign Home V2 Color Palette

## Task

Redesign the `/home-v2` color palette away from generic beige while preserving the current Home V2 layout, typography, motion, route behavior, and content.

## Design Direction

- Use a premium soft-structural palette: cool porcelain, mist grey, pale jade, deep ink, restrained burgundy, and muted champagne.
- Keep warmth through image treatment, gold glows, and burgundy accents rather than a beige page wash.
- Avoid one-note beige/cream dominance.
- Preserve double-bezel frames and existing section structure.

## Steps

1. Update Home V2 CSS tokens and background gradients.
2. Adjust line, card, nav, and image-frame material colors through existing variables.
3. Add subtle cool ambient background layers without decorative orbs.
4. Build and visually verify desktop/mobile preview.
5. Commit and push the scoped change.

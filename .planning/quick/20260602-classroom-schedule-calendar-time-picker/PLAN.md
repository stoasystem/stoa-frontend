# Quick Task: Classroom Schedule Calendar Time Picker

**Created:** 2026-06-02
**Status:** Complete

## Request

The Online Classroom schedule page used four preset time buttons. It should provide a calendar and a wheel-like time selector so users can choose dates and times more flexibly.

## Plan

- Replace preset time buttons with a calendar date picker and scrollable time selector.
- Show the selected date/time in the session preview.
- Pass the selected start time through the existing schedule request contract.
- Update the demo classroom scheduling service so created sessions use the selected time and the session type duration.
- Run lint/build and verify the schedule flow in browser.

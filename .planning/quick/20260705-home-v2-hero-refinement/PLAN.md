# Home V2 Hero Refinement

## Goal

Refine the `/home-v2` Hero after grilling the design details with the user, reducing visual clutter and making the first viewport feel more like a high-end Swiss education service.

## Decisions

- Hero first impression should be 85% high-end education service and 15% product proof.
- Use a short, brand-like H1 rather than a long multi-line explanatory headline.
- Use one main natural family-learning image with one minimal proof panel.
- Remove multi-card proof clutter from the Hero.
- Desktop composition should be roughly 45% copy and 55% image.
- Mobile order should be copy, CTA, image, proof.
- Hero CTA should be `Start learning` plus a very light `For parents` secondary entry.
- Floating navigation should keep Parents, Teachers, Pricing, and an easy-to-find but low-noise `Log in` pill.

## Acceptance

- Current `/` homepage remains unchanged.
- `/home-v2` Hero no longer uses multiple overlapping proof cards.
- Top nav uses `Log in`, not `Start learning`.
- Hero copy is shorter and calmer across EN/DE/FR/IT.
- Lint, build, and focused visual smoke pass.

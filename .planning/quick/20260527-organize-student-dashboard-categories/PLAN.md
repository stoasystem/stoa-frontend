# Quick Task: Organize Student Dashboard Categories

Date: 2026-05-27

## Problem

The student dashboard shows useful content, but too many unrelated cards appear in one long flow. Plan/access, learning actions, recent activity, progress, weak topics, and teacher feedback need clearer grouping.

## Scope

- Reorder the dashboard around the student's next action first.
- Move weekly summary stats into a compact snapshot column.
- Group review content behind tabs so recent questions, progress, and teacher support are not all visible at once.
- Move plan/access to a bottom account section.
- Keep existing dashboard content and routes intact.

# Phase 166 UI Spec

## Direction

Luxury/refined editorial education interface. Practice is presented as a calm learning doorway, not a game panel.

## Layout

- Section after hero.
- Two-column desktop layout: positioning copy left, flow/cards right.
- Responsive single-column mobile layout.

## Visual Rules

- Burgundy primary actions.
- Warm neutral surface.
- 8px card radius.
- No cartoon rewards or bright game colors.

## Acceptance

- Primary CTA remains Start learning.
- Secondary CTA explains Practice.
- Flow reads Practice -> Hint -> Learning Chat -> Teacher Support -> Parent Report.

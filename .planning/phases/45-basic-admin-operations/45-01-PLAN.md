# Plan

1. Add typed admin API contracts for usage summary and feedback list.
2. Add TanStack Query hooks for the two admin backend boundaries.
3. Replace the old admin placeholder with a basic operations dashboard showing environment, version, pilot status, and links to scoped admin views.
4. Add `/admin/usage` with usage summary cards when data is available and a backend-pending placeholder when the endpoint is unavailable.
5. Add `/admin/feedback` with a feedback list when data is available and a backend-pending placeholder when the endpoint is unavailable.
6. Add admin routes under the existing protected admin role route.
7. Verify TypeScript/build and lint.

# Out Of Scope

Full admin user management is deferred. This phase does not add user search, role editing, account status changes, support case workflows, pricing, privacy, onboarding, or support documentation changes.

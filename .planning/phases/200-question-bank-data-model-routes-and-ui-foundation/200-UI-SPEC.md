# Phase 200 UI Spec

**Aesthetic direction:** restrained academic-library interface. Dense but calm, metadata-rich, and clearly different from Practice Path's roadmap.

**Rules:**
- Use cards only for individual resources and framed tools.
- Use compact badges, metrics, and filter controls.
- Avoid game-map visuals, rewards, hearts, streak pressure, and loud celebrations.
- Preserve STOA burgundy/charcoal/warm surface language.

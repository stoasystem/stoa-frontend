# Phase 167 UI Spec

## Direction

Operational student dashboard with restrained premium cards. Highest visual priority is the next learning action.

## Layout

- Continue Practice and Ask Question cards sit above recent activity.
- Practice lesson feedback keeps hint/explanation/retry actions grouped.
- Chat context card remains compact.

## Acceptance

- Student sees Practice and Learning Chat as related but distinct.
- Teacher support is delayed and visually secondary.
- No button text overflows on desktop or mobile.

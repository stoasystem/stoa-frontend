# Phase 207 Plan: Shared Upload Components and Modal Experience

## Goal

Build a consistent upload UI kit so learning surfaces can add file/photo upload without duplicating controls or accessibility behavior.

## Scope

- Upload button and photo capture button.
- Drag/drop dropzone with browse fallback.
- Attachment preview cards and preview list.
- Status badge, error message, modal, and inline panel.
- Keyboard-reachable controls with labels, status/alert regions, and filename-specific action labels.

## Acceptance

- Students can browse, capture, drag/drop, preview, remove, retry, and complete uploads.
- Modal closes through visible and keyboard actions and returns focus to the opener.
- Inline panel stays visually secondary to the page's primary learning task.

# Phase 210 Plan: Practice Path Schoolwork Upload Entry and Context Handoff

## Goal

Add a lightweight Practice upload entry so students can bring schoolwork into Learning Chat without weakening the guided Practice roadmap flow.

## Scope

- Add compact upload panels to Practice overview and topic roadmap pages.
- Use the shared upload hook/component system.
- Save Practice source context and attachment metadata for Chat.
- Keep copy focused on step-by-step learning guidance.

## Acceptance

- Practice upload is visible but secondary to guided roadmap and lesson CTAs.
- Completed upload opens Chat with Practice source context.
- Copy avoids generic storage and reward language.

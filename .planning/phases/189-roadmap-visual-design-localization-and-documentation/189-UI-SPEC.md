# Phase 189 UI Spec: Roadmap Polish

## Desktop

Use a vertical path with restrained alternating offsets. Connectors should visually imply forward movement without drawing a playful map world.

## Mobile

Use a single readable vertical path. Nodes should stay full-width with clear status labels and no horizontal overflow.

## Localization

German and Italian CTA labels can be longer, so buttons and node footers must wrap safely. French apostrophes must render correctly.

## Anti-Patterns

- High-saturation game green.
- Mascot, shop, gem, streak, heart, or leaderboard language.
- Large decorative map backgrounds.
- Viewport-scaled type or text that overlaps its container.

# Phase 213 UI Spec

- Student Dashboard card should read as a compact learning action card, not a marketing block.
- `/classroom` should show upcoming session first, then instant help/scheduling options, then recent sessions.
- `/classroom/schedule` should be form-first with segmented controls for quick student choices.
- Upload controls should be reused from the shared upload foundation to preserve attachment semantics.
- Copy must distinguish scheduled classroom from instant help started through Learning Assistant or teacher text.

# Phase 169 UI Spec

## Direction

Efficient tutor operations UI. Practice context should be visible early and compact enough to scan.

## Layout

- Practice context card appears before general request transcript.
- Small fact tiles show source, attempts, answer, and hint state.

## Acceptance

- Tutor can identify the stuck Practice step without reading the full chat first.
- Wording remains teacher-centered and non-game-like.
